Settings for conditional IPCW net benefit (optional)

Description

Conditional inverse probability of censoring weighting (cIPCW) allows censoring to depend on covariates: it assumes censoring is independent of the event time given the covariates of the censoring model. It is used when nb_val() is given cipcw, and most analyses need nothing more than the covariates, cipcw = ~ age + nodes (option 1 below, with the default truncation). cipcw_control() is only needed for the other options: your own censoring model, given weights, another truncation, ties, or your own predict and refit functions.

Usage

cipcw_control(
  formula = NULL,
  model = NULL,
  weight_event = NULL,
  weight_horizon = NULL,
  min_prob = 0.02,
  ties = c("left", "right"),
  predict_function = NULL,
  refit_function = NULL
)

Arguments

formula Option 1: the covariates of the censoring, a one-sided formula such as ~ age + nodes (variables of data), for a Cox model fitted by voipred. Give one of formula, model or the two weights.
model Option 2: a survival model fitted to the censoring times of the validation data data passed to nb_val() (same patients), with censoring as the event, e.g. coxph(Surv(time, status == 0) ~ x, data = val).
weight_event, weight_horizon Option 3: two numeric vectors, one positive finite value per row of data (in its row order), given together: weight_event is the inverse probability of remaining uncensored just before each patient’s own time, 1/G(T_i- X_i), used for patients with an event (of any cause) by the horizon; weight_horizon is the inverse probability of remaining uncensored at the horizon, \(1/\hat G(\tau \mid X_i)\), used for patients event-free at the horizon. Values for the other patients are ignored (any positive number will do). Unstabilized weights only.
min_prob Truncation, for every option: censoring probabilities below min_prob (options 1 and 2), or weights above 1 / min_prob (option 3), are set to that limit. A single number strictly between 0 and 1; default 0.02 (weights at most 50). NULL: no truncation.
ties Options 1 and 2, and only matters for a censoring model whose survival curve has steps (e.g. Cox, Kaplan-Meier, forests, trees): “left” (default) uses the probability of remaining uncensored just before each patient’s own time, so a censoring step at exactly that time is not included (the usual convention, as for Kaplan-Meier: an event tied with a censoring comes first); “right” includes it. For smooth (parametric) censoring models both give practically the same result.
predict_function Option 2, optional: a function(model, newdata, times) returning, for each row of newdata, the probability of remaining uncensored at that row’s time in times (the censoring survival \(G(t \mid X)\), not a risk). It may instead return a curve per row, list(time = <grid>, surv = <n x grid matrix>), which voipred reads at each row’s own time. Use it for a censoring model voipred cannot predict from by itself, or to predict in your own way; it then replaces voipred’s own prediction. Requires model.
refit_function Option 2, optional: a function(data, weights) returning the censoring model fitted to data (the validation data given to nb_val(), restricted to the patients with a positive weight in a draw) with case weights weights (the Bayesian-bootstrap weights of the draw, positive and averaging 1, times the case weights of nb_val() if any; in evsi() also whole numbers for the pooled samples), e.g. function(data, weights) coxph(Surv(time, status == 0) ~ x, data = data, weights = weights). Used by the value-of-information functions to refit the censoring model in every draw (see "Uncertainty"). Needed for a censoring model voipred cannot refit with case weights by itself.

Details

There are three ways to give the censoring information:

1. The covariates of the censoring (formula =, or simply cipcw = ~ age + nodes in nb_val()). voipred fits a Cox model of the censoring times of the validation data on them, coxph(Surv(time, censored) ~ age + nodes), with only true censoring as the event (with competing risks, patients with a competing event are not censored), weighted by the case weights of nb_val() if any, and refits it in every draw of the value-of-information functions. A two-sided formula (e.g. Surv(time, status == 0) ~ age + nodes) is fitted as it is.

2. A fitted censoring model (model =, or cipcw = <model> in nb_val()). Fit any survival model to the censoring times in the validation data, i.e. with the censored patients as the "events": Surv(time, status == 0). With competing risks, only true censoring is censoring: patients with a competing event are not censored (Surv(time, status == “censored”), not status != cause). voipred predicts from the model the probability of remaining uncensored just before each patient’s own time and at the horizon, in the same way as it predicts risks from a model in nb_val(): through riskRegression::predictRisk() (e.g. coxph with x = TRUE, rms::cph, survreg, flexsurvreg, ranger, randomForestSRC, a Kaplan-Meier prodlim fit), or voipred’s own code for models riskRegression cannot handle (coxph without x = TRUE, aorsf, partykit survival trees, rstpm2::stpm2, mgcv::gam with cox.ph()). For any other model, give predict_function (or the weights, option 3). Where the model’s outcome can be read from its formula, voipred checks it against data: it stops if the model was fitted to the event (for competing risks: to the cause of interest, to another cause or to all events together), and warns if the check is not possible or if the model was fitted to a different number of patients than data has.

3. Weights (weight_event =, weight_horizon =): one value per row of data, the inverse probabilities of remaining uncensored just before each patient’s own time and at the horizon, i.e. \(1/\hat G(T_i- \mid X_i)\) and \(1/\hat G(\tau \mid X_i)\). Only the weights of patients with an event by the horizon (weight_event; including competing events) and of patients event-free at the horizon (weight_horizon) are used. They must be unstabilized: stabilized weights bias this estimator.

Flexible censoring models. A flexible model (e.g. a forest) fitted and evaluated on the same patients overfits their censoring times, and its weights are biased. Use cross-fitting: split data into folds, fit the censoring model on all folds but one, predict the censoring probabilities for the held-out fold, and give the resulting weights through option 3 (in nb_val() only: see "Uncertainty").

Truncation. By default, censoring probabilities below min_prob = 0.02 (options 1 and 2), or weights above 1 / min_prob = 50 (option 3), are truncated, with a warning saying how many of the used ones were. With min_prob = NULL there is no truncation: voipred then warns when some used probabilities are below 0.01 (weights above 100), a sign of near-violations of positivity, and stops if a probability is exactly 0.

Uncertainty (value of information). The censoring model is estimated from the validation data, so its uncertainty is part of the uncertainty about the net benefit. The value-of-information functions (evpi(), evsi()) therefore refit the censoring model in every draw of the Bayesian bootstrap, with that draw’s weights as case weights, and recompute the censoring weights from it. The refit is done:

  • for option 1, automatically (voipred’s own Cox model);

  • with refit_function, if given;

  • otherwise automatically for the censoring models whose case weights voipred knows: survival::coxph, survival::survreg, rms::cph, rms::psm, flexsurv::flexsurvreg (also flexsurvspline) and prodlim::prodlim: the model’s own call, with the draw’s data and the draw’s weights as case weights;

  • otherwise it stops and asks for refit_function: other models take weights under other names or with another meaning (e.g. ranger’s case.weights are sampling probabilities), so voipred does not guess.

Patients with a weight of 0 in a draw are left out of the refit. Given weights (option 3) cannot be refitted, so they can be used in nb_val() but not in the value-of-information functions. nb_val() itself always uses the model as given.

Value

An object of class cipcw_control.

Examples

library("voipred.dev")

library(survival)
rott <- rotterdam
rott$years <- rott$dtime / 365.25
df_dev_survival <- rott[1:1500, ]
df_val_survival <- rott[1501:2982, ]
cox <- coxph(Surv(years, death) ~ age + size + nodes + grade,
             data = df_dev_survival)
# the predicted risks of death by 5 years
sf <- survfit(cox, newdata = df_val_survival)
df_val_survival$p5 <- 1 - summary(sf, times = 5)$surv[1, ]

# usually only the covariates of the censoring are needed (no cipcw_control())
nb_val(data = df_val_survival,
       predicted_risk = df_val_survival$p5,
       outcome = ~ Surv(years, death),
       horizon = 5,
       thresholds = c(0.1, 0.2, 0.3),
       cipcw = ~ age + nodes + grade)
